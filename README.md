- 🔹 **JavaScript**

---

## 📚 Learning Approach

My goal is to understand the logic behind each problem rather than simply memorizing solutions.

***My workflow:***

1. Read and understand the HackerRank problem.
2. Rewrite the problem in a simpler and clearer way if necessary.
3. Solve the challenge independently using Visual Studio Code.
4. Test and review the solution.
5. Submit the verified solution to HackerRank.
6. Save the final solution in this repository.
